# NGA Excel 摸鱼皮肤

桌面浏览器里用的 Tampermonkey 脚本。打开 NGA 时盖上一层 Excel，文件名是 `CW3_Sprint_联调清单_202609.xlsx`。当前版本 **1.10.28**。

脚本文件：`nga-excel-moyu.user.js`。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 新建脚本，把 `nga-excel-moyu.user.js` 全文贴进去，保存。
3. 第一次保存如果询问 `GM_xmlhttpRequest`、`GM_getValue`、`GM_setValue`、`GM_openInTab`，全部允许。`GM_openInTab` 用来在后台开标签，当前页留在原处。
4. 打开 [ngabbs.com](https://ngabbs.com/) 并登录。未登录时发帖、回复、赞会弹出登录。

生效站点：`ngabbs.com`、`bbs.nga.cn`、`nga.cn`、`nga.178.com`、`bbs.ngacn.cc`。图片站和附件直链不会盖上这层皮，避免看图时还是表格。

只做桌面。手机版没适配。

## 页面

底栏有四张表：

| 表 | 作用 |
|---|---|
| 工单看板 | 板块列表和帖子，平时看这个 |
| 接口核对 | 老板键切过去的接口表 |
| Training用例 | 固定的用例表 |
| 字段映射 | 固定的字段表 |

板块列表的列是 CWM、需求说明、Assignee、评论、Updated、Status、模块、环境。楼里的列是 #、Author、Time、Comment、Type、Source。

Updated 显示页面上的「刚才」「今天 13:56」「5分钟前」。Comment 折行最多 3 行，全文在右侧明细。

列表和楼内的列宽、列顺序分开保存。拖过的宽度在更新脚本后还在。

## 看帖和翻页

- 单击选中，双击、Enter 或「打开」进帖。
- 鼠标中键在后台开新标签。
- 上方「环境」换板块。「返回列表」回到板块。
- 合集板块（例如网事杂谈）里，帖子标题旁的子版会显示在「模块」列。上方「子版」可以多选，留下当前列表里属于这些子版的帖子，以及没标子版、发在本版的帖子，不会跳进子版。其它子版的帖子不显示。一个都不选就是全部。勾选按板块记住，刷新后还在。
- 版头导读默认收起，单击「版头」那一行展开，再单击收起。导读条目仍用双击或 Enter 打开。
- 帖子被删、审核未通过、权限不足或找不到主题时，Comment 里显示 NGA 的提示。页面上的「查看所需的权限」不会再被当成要登录。
- 上一页、下一页、页码 Go、楼层 Go、末页（→|）。
- 板块列表和楼内滚到底都会接下一页。
- 动图和视频在右侧预览里直接播放。gif 用图片循环，NGA 的 gif 转 mp4 用静音循环播放。普通视频带控制条。
- 明细栏左边有一条灰色拉条，拖它可以改预览宽度。松手后记住，刷新还在。
- 翻页不整页刷新，地址栏会跟着变。
- 广告中转页会直接进目标页。
- 顶栏搜索框按板块搜索。Ctrl+F 在当前表格里找，F3 下一个。

## 列和预览

- 鼠标放在表头右缘，拖动改列宽。双击右缘按内容撑开。
- 按住表头拖到另一列，改列顺序。文件菜单里的「重置列序」只重置当前这一页（列表或楼内）。
- 明细窗左缘可以拖宽度。
- 引用和本楼分开显示。贴条在明细里按一条一条的 Notes 显示。

## 图片

正文里的图不直接铺开。明细底部有「图 1」「图 2」。点开后是约 2cm 的小图，可以复制链接，或新标签打开并留在本页。

NGA 附件常见的 `./mon_...jpg` 和懒加载地址会转成 `img.nga.cn` 上的图片地址。

## 回复和帖子操作

在楼内选中一行后，用右侧明细：

| 按钮 | 作用 |
|---|---|
| Score / Pass / Fail | 赞、支持、反对 |
| Pin | 收藏 |
| Assignee | 打开作者 |
| Owner | 只看该作者 |
| Revise | 编辑这一楼 |
| Remove | 删除，再点一次才确认 |
| From row | 把当前楼引用进回复框 |
| Subtask | 发贴条 |
| Attach | 上传图片或附件 |
| Save | 发送。Ctrl+Enter 同样发送 |

发新帖用板块页的发表入口。需要验证码或登录时会弹出输入框。

文件菜单还有：刷新、复制链接、我的主题、返回列表、只看该作者、精华区、转到末页、显示原版。

## 快捷键

| 键 | 作用 |
|---|---|
| Alt+Q、F9、反引号键 | 在工单看板和接口核对之间切换 |
| F10、Ctrl+Shift+Q | 显示或收回原版 NGA |
| F5、Ctrl+R | 刷新当前页 |
| Ctrl+F、F3 | 在表格里查找 |
| Ctrl+C | 复制当前格 |
| Ctrl+Shift+C | 复制当前行链接 |
| 方向键、Tab | 移动选中格 |
| Enter | 打开选中行 |
| Esc | 关闭查找、菜单和弹窗 |

打开页面后底部会短暂提示这几组常用键。
